# Первый прогон на Meta Quest — чек-лист

Прототип ни разу не запускался на шлеме (у разработчика его не было). Этот список — что проверить в первую очередь,
от «запускается ли вообще» до деталей. Отмечайте результат и пишите в issue номер пункта.

## 0. Установка
- [ ] `adb install -r pvz-mr.apk` из последнего релиза (<https://github.com/paradisemay/pvz-mr/releases>) проходит.
- [ ] Приложение есть в «Неизвестных источниках», запускается, не падает в первые 30 с.

## 1. Смешанная реальность (T001, T008)
- [ ] Видна настоящая комната (passthrough), а не чёрный/серый фон.
- [ ] Появляется запрос разрешения «пространственные данные» (`USE_SCENE`); после «Разрешить» коробки поставки падают
      на настоящий пол/стол, после «Запретить» игра всё равно проходится (пол по умолчанию).
- [ ] Стойка стоит перед игроком; «СТОЙКУ КО МНЕ» переносит её туда, куда смотрит игрок, вместе с коробками.
- [ ] Табло, зона выдачи, экран сканера отображаются нормально (в редакторе с целью Android они были заглушками —
      см. отчёт, раздел 5).

## 2. Управление (контроллеры)
- [ ] Сканер берётся кнопкой захвата, скан — курок; луч сканера виден.
- [ ] Коробки берутся и бросаются; коробка, упавшая сквозь пол, возвращается на место.
- [ ] Кнопки стартового меню нажимаются лучом/рукой: сложности, «СТОЙКУ КО МНЕ», «СБРОСИТЬ СКЛАД», «ТЕМА».

## 3. Читаемость (на расстоянии вытянутой руки)
- [ ] Табло и список «ЗАКАЗЫ» читаются без наклона головы.
- [ ] Экран сканера: все строки видны («Заказ №… / НУЖНАЯ КОРОБКА», «ПОХОЖ — НЕ ТОТ!»).
- [ ] Маленькие кнопки «СБРОСИТЬ СКЛАД» и «ТЕМА» (11 см) читаются — если нет, это первое, что увеличить.
- [ ] Памятка «КАК ИГРАТЬ» читается.

## 4. Звук
- [ ] Писк сканера, «успех»/«ошибка» слышны.
- [ ] Голос клиентов (процедурная «речь») слышен и не раздражает; громкость относительно остальных звуков нормальная.

## 5. Полная смена (Обычная)
- [ ] Клиенты подходят, очередь до двух, номер заказа на табло и в реплике.
- [ ] Поставка падает с потолка в досягаемые места; приёмка сканером; «большой заказ» из трёх коробок выдаётся.
- [ ] Пакет, возврат, срочный и забывчивый клиент, похожий номер — встречаются за 1–2 смены.
- [ ] Таймер на табло; при «время вышло» очередь уходит, итоги «время вышло».
- [ ] Конфетти при выдаче видно и не мешает; вспышка экрана сканера заметна.
- [ ] Итоги: рекорд, строка карьеры; «Новая смена» начинает заново.

## 6. Между сессиями
- [ ] Расставить коробки по комнате, выйти (снять шлем / закрыть приложение), зайти снова — коробки там же
      (относительно стойки). Если встали в мебель — «СБРОСИТЬ СКЛАД» возвращает их.
- [ ] Рекорды и очки карьеры сохраняются; открытая тема переключается кнопкой «ТЕМА».

## 7. Производительность
- [ ] Плавно (цель — 72 FPS), без заметных рывков при поставке, конфетти и речи клиентов.

## Что делать с результатами
Каждый провал — issue в <https://github.com/paradisemay/pvz-mr/issues> с номером пункта и, по возможности, видео
(запись экрана Quest). Первые кандидаты на исправление по рискам из отчёта: материалы Unlit, читаемость маленьких
кнопок, громкость голоса, привязка склада к комнате (сейчас — относительно стойки).
