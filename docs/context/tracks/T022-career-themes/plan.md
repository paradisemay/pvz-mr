## По итогам ревью
- Каталог тем — `ScriptableObject` (названия, пороги, цвета); Core получает только id и пороги и проверяет список.
- Выбор темы сохраняется по id через `ITextStore` (по индексу он сломался бы при вставке новой темы — тест).
- Карьера вынесена из директора в `CareerKeeper`; директор только сообщает очки завершённой смены.
- Меню целиком рисует презентер (рекорды + карьера), без второго «писателя» нижней строки.
- Вес сложности для карьерных очков: Лёгкая 50 %, Обычная 100 %, Сложная 150 % (лёгкая смена без таймера не «ферма»).
- Тесты не читают настоящую карьеру разработчика (хранилище подменяется до загрузки сцены).
- `IScoreStore` — общий целочисленный хранилищем игрока; у владельцев свои префиксы ключей (`pvz.best.`, `pvz.career.`).
