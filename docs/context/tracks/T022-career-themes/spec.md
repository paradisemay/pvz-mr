# T022 — Карьера и темы стойки

## Зачем
Концепция: «Статистика и прогрессия: … открывать новые улучшения для ПВЗ», «рейтинг и разблокировки», «кастомизация ПВЗ».
До сих пор между сменами сохранялись только рекорды; нечего было «открывать».

## Что делаем
- **Карьера:** очки каждой завершённой смены складываются (`pvz.career.points`) с весом сложности: Лёгкая — 50 %,
  Обычная — 100 %, Сложная — 150 % (`ShiftSettings.careerPointsPercent`), чтобы лёгкая смена без таймера не была
  самым выгодным способом копить очки. Нулевых и отрицательных вкладов нет.
- **Темы стойки:** «Классика» (сразу; собственные материалы стойки), «Мята» (1000), «Ночь» (2500), «Золото» (5000) —
  цвет корпуса, столешницы и акцентов стойки и табло.
- **В меню:** строка «Карьера: N · до темы «…»: M»; кнопка «ТЕМА: …» переключает открытые темы по кругу. Выбор
  запоминается **по id** (`pvz.career.theme`); сохранённая, но не открытая или неизвестная тема → первая.
- **В итогах смены:** «Карьера: N (+очки)» и «Открыта тема «…»!», если смена её открыла.

## Архитектура
- Core: `Career` (накопление, пороги, выбор) получает список тем извне и проверяет его (первая открыта сразу,
  пороги по возрастанию, id уникальны); `CounterTheme` — только id и порог.
- Runtime: каталог тем — один `ScriptableObject` `CounterThemeCatalog` (id, порог, название, цвета; создаётся билдером,
  дальше правится дизайнером). Не в `ShiftSettings`: карьера — общая для всех сложностей.
- `CareerKeeper` — отдельный компонент (как `WarehouseLayoutKeeper`): владеет `Career`, красит стойку (`CounterSkin`,
  блоки свойств поверх материалов), обслуживает кнопку `ThemeButton`. Директор только сообщает очки завершённой смены
  (одна защищённая try/catch строка в `EndShift`).
- Меню целиком рисует `ShiftPresenter.ShowDifficultyMenu` (рекорды + строка карьеры); тексты — статические функции презентера.
- Хранилища: очки — в общем целочисленном `IScoreStore` (как рекорды, свой префикс ключа `pvz.career.`), выбор темы —
  в `ITextStore`. Тесты подменяют их до загрузки сцены (`CareerKeeper.StoreOverride`).

## Критерии готовности
- EditMode: накопление, вес сложности, однократное открытие, несколько тем за смену, нули/минусы, выбор по id
  (не ломается при вставке новой темы), неоткрытая/неизвестная тема, переполнение, проверка списка тем.
  Editor: тексты; каталог в проекте полон; ссылки `CareerKeeper`/кнопки/«кожи» в сцене.
- PlayMode: меню показывает карьеру; кнопка красит стойку в открытую тему и возвращается к «Классике»; итоги смены
  содержат строку карьеры.
