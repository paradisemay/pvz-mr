## По итогам ревью
- Однозначность подсказки проверяется по всем заказам смены (склад, ожидающая и плановая поставка), а не только по складу.
- `UrgentPatienceFactor` проверяется в Core: (0, 1] — иначе 0 означал бы «ждёт вечно».
- «Ушёл без заказа» и подсказка обучения при неверной коробке не раскрывают номер забывчивого клиента.
- Приветствие собирается из двух частей (срочность + как назван номер) вместо матрицы вариантов.
- PlayMode-тест проверяет и реплику «не мой заказ», и что сканер показывает полный номер.
- Спецификация поправлена: сканер намеренно показывает номер; `architecture.md` — раздел «Решения T014».
- Отложено: флаги вместо позиционных `bool` в конструкторе `Order` (вызовы используют именованные аргументы);
  «похожие заказы» потребуют общего помощника «занятые окончания» в Core — решить в спецификации следующего трека.
