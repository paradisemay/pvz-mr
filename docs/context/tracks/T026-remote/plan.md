## По итогам ревью
- Автопилот проверяет, что у стойки тот же клиент: раньше после ухода клиента он отдавал коробки старого заказа следующему.
- Команда, которую игра не взяла за 30 с (шлем снят), отменяется, а не выполняется позже; на паузе ответ сразу.
- Токен в первой строке соединения (loopback доступен всем приложениям шлема), простаивающее соединение закрывается.
- `autoplay on` после конца смены — ошибка, а не «включён навсегда».
- Запись кадров ограничена (1800), текстуры уничтожаются, папки записей уникальны и сортируемы.
- Скрипты: проверки adb/ffmpeg, таймаут чтения, токен.
- Тесты: автопилот без ошибочных выдач и ушедших клиентов; токен; патч манифеста — чистая функция с тестом.

## Найдено на устройстве
- Без контроллеров Quest не пускает игру («Переключитесь на контроллеры»): у игроков контроллеры есть, но для
  отладки без рук это стена — в отладочной сборке объявлена поддержка рук (`required=false`).
- Встроенная запись Quest (`screenrecord`) снимает настоящую комнату вместе с игрой; в неё попадает и то, что вокруг
  (отражения в окне) — записи проверяются по кадрам перед публикацией.
- Рекорды и карьера на устройстве переживают переустановку APK (`PlayerPrefs`).
- Для съёмки лежащим шлемом добавлена команда `area` (сдвиг игровой зоны), иначе стойка закрывает весь кадр.
