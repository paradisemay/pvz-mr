# T009 — Рекорды по сложностям

## Зачем
Из концепции, раздел «Прогрессия»: итоговая статистика и стимул сыграть ещё. Лучший результат по каждой сложности
сохраняется между запусками.

## Правила
- После смены очки сравниваются с рекордом выбранной сложности; если больше — «НОВЫЙ РЕКОРД!» в итогах.
- В стартовом меню табло показывает рекорды: «Рекорды: Лёгкая 450 · Обычная 0 · Сложная 0».
- Рекорд хранится локально на устройстве.

## Модель
- Core: `IScoreStore` (чтение/запись числа по ключу), `BestScores` — правило «новый рекорд» без UnityEngine.
- Runtime: `PlayerPrefsScoreStore`; директор фиксирует результат при конце смены; тексты — в презентере/итогах.

## Критерии приёмки
- EditMode: первый результат — рекорд; меньший — нет; разные сложности независимы; ключи стабильны.
- PlayMode: после смены рекорд сохранён и показан в итогах (хранилище подменено на память).
