# T023 — Большой заказ

## Зачем
В «Игровых ситуациях» концепции — «заказ состоит из большого количества товаров». Многопредметные заказы есть с T005,
но до сих пор только по две коробки.

## Что делаем
- Поставка привозит заказ 3307 из **трёх** коробок (BOX-101, BOX-102, BOX-104) — табло показывает «Коробок: 3»,
  список заказов и подсказки работают как с любым многопредметным заказом. В поставке теперь 4 коробки.
- Окончания номеров по-прежнему различны (07, 18 и складские 35/81/12), похожая пара 2781/2718 сохраняется.

## Архитектура
- Только данные (`ShiftSettings` по умолчанию; пресеты пересозданы) — правила многопредметных заказов не меняются.
- Editor-тест охраняет данные: в поставке Обычной и Сложной есть заказ из трёх и более коробок.

## Критерии готовности
- Editor: «большой заказ» в пресетах; PlayMode: полная смена принимает 4 коробки поставки и выдаёт заказ из трёх.
- PR в `dev`; релиз v1.15.0.
