## По итогам ревью
- Переходы — именованные и проверяемые (`Open` / `Serve` / `Abandon` / `Leave`), недопустимый — исключение.
- «У стойки» — по событиям стойки, на которые `Shift` подписан первым (книга актуальна для презентера; работает и при
  открытии стойки напрямую).
- `Changed` — после обновления очереди и один раз на уход всей очереди по времени.
- Тест: открытые записи книги всегда совпадают с очередью `Shift` (две правды пока охраняются тестом; следующий шаг —
  очередь как вид книги).
- Цвета строк — из палитры табло (`CounterBoard.Accent/Good/Bad/Muted`); панель списка — явная ссылка, не «родитель текста».
- Список остаётся рядом с итогами после смены — журнал смены (записано в spec).
