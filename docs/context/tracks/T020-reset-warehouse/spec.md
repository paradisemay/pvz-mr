# T020 — Кнопка «Сбросить склад»

## Зачем
С T017 раскладка склада сохраняется между сессиями. Если мебель в комнате переставили или игрок встал иначе
(раскладка повторяется относительно стойки), коробки могут оказаться в неудобных местах. Нужен способ вернуть всё
как было — это отложенный пункт из T017.

## Что делаем
- В стартовом меню, за кнопкой «Стойку ко мне», — кнопка «СБРОСИТЬ СКЛАД».
- Нажатие: сохранённая раскладка забывается (сохраняется пустая), коробки склада встают на места, где их поставила
  сцена. В следующей сессии восстанавливать нечего.
- Меню видно только до начала смены, поэтому посреди смены коробки не прыгают.

## Архитектура
- `WarehouseLayoutKeeper.ResetLayout` — тот же компонент, что ведёт раскладку; места по умолчанию он запоминает
  в `Awake`, до восстановления сохранённых.
- `ResetWarehouseButton` — по образцу `RecenterButton` (`XRSimpleInteractable`, `Press()` для тестов); собирается билдером.

## Критерии готовности
- PlayMode: коробка, восстановленная на месте игрока, после нажатия возвращается на исходное место; следующая сессия
  ничего не восстанавливает. Editor: ссылки кнопки в сцене.
