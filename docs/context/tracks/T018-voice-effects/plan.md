- Голос молчит вне Play Mode (скриншоты вызывали `Destroy` в режиме редактора).
- Один буфер и один клип на клиента: без аллокаций и `AudioClip.Create` на каждую реплику; `Play` вместо `PlayOneShot`
  (`Stop` действительно обрывает предыдущую реплику).
- Вспышка — временный блок свойств поверх цвета материала, снимается по окончании (без зашитого цвета экрана).
- Эффект Доплера у голоса выключен (слушатель — голова игрока).
- Счётчики растут только при реальном действии; тест проверяет, что конфетти действительно летит; голос клиента —
  в проверке ссылок префаба.
- Вспышка — для всех оценённых сканов (не только «нужная/чужая»).
- `Babble` — отдельный файл; `FeedbackEffects` — явный параметр презентера.
