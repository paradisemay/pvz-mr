# T047 — Потеряшки (#86)

Из #73: «чтобы были потеряшки-заказы». Трактовка: **потеряшка** — заказ, коробки которого нет на складе (её не
привезли или потеряли). Игрок должен понять, что коробки нет, и отметить это, а не искать бесконечно.

## Решение
- **Пропавшие коробки** (`StockPlan.PickMissing`, Core): при начале смены с вероятностью сложности (Лёгкая 0 %,
  Обычная 10 %, Сложная 15 %) у заказа пропадает одна коробка — она остаётся в заказе, но не падает из люка.
  Запасные коробки не трогаются; у многокоробочного заказа пропадает только одна. Детерминировано для зерна.
- **«НЕ НАЙДЕН»** — клавиша компьютера на экране смены (`Shift.DeclareNotFound`):
  - у заказа у стойки действительно нет коробки — заказ закрывается как **потеряшка**: клиент уходит спокойно
    («Ничего страшного, зайду, когда привезут»), +30 очков за честность, в списке «№… — потеряшка», остальные коробки
    этого заказа больше никому не продаются;
  - коробка есть на складе — штраф −50, клиент ждёт дальше («Коробка есть на складе!»).
- **Итоги**: «Потеряшек: N», «Ложных «Не найден»: N» (красным); потеряшка — обработанный заказ для рейтинга.
- Автопилот пульта нажимает «Не найден», если коробки заказа нет в комнате.

## Проверка
- EditMode (`LostOrderTests`): потеряшка закрывается за очки, не продаётся дальше, помечена в книге; «Не найден» при
  наличии коробки — штраф, клиент ждёт; выбор пропавших — по одной коробке, без запасных, детерминирован.
- PlayMode (`LostOrderPlayTests`): пропавшей коробки нет в комнате, клавиша закрывает заказ, на табло и в списке
  «потеряшка»; ложное «Не найден» — штраф, клиент у стойки.
- Quest 3: сложная смена автопилотом — 13/14 выдано, 1 потеряшка (№1435).
- Скриншоты: `30_lost_order`, `31_not_found_key`.
