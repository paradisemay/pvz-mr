# T008 — Готовность к устройству

## Зачем
Шлема у разработчика нет, поэтому заранее закрываем известные проблемы первого запуска на Quest.

## Что сделано
- **Разрешение `com.oculus.permission.USE_SCENE`.** Без него Meta не отдаёт данные комнаты (плоскости).
  `ScenePermissionGate` держит `ARPlaneManager` выключенным до согласия игрока. При отказе игра работает
  без мебели: коробки лежат на невидимом полу.
- **«Стойку ко мне».** Кнопка в стартовом меню переносит всю игровую зону (стойку, коробки, путь клиентов) перед игроком —
  на случай, если автоматическое выравнивание поставило стойку в мебель.
- **Стартовое меню** (`Start Menu`) — общий корень для кнопок сложности и «Стойку ко мне», скрывается при начале смены.
- Пересборка APK — проверка, что код под Android компилируется.

## Критерии приёмки
- PlayMode: кнопка переносит зону перед игроком; меню скрывается при старте; в редакторе разрешение не блокирует.
- APK собирается.
