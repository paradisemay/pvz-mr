# T013 — Возвраты

## Зачем
Из концепции: «принять возврат», игровое событие «возврат товара». Разнообразит поток клиентов: не каждый
приходит забирать заказ.

## Правила
- Новый клиент в очереди с шансом `returnChancePercent` (Лёгкая 0 %, Обычная 20 %, Сложная 35 %) приходит вернуть
  коробку из заказа, выданного раньше в эту смену. Каждая выданная коробка может вернуться не больше одного раза.
- Возвраты появляются только пока на складе есть что выдавать — конец смены они не затягивают; уже стоящий в очереди
  возвращающий клиент будет обслужен до конца смены.
- У стойки клиент ставит коробку в зону выдачи: «Хочу вернуть товар из заказа №N». Игрок сканирует её —
  «ВОЗВРАТ ПРИНЯТ», +30 очков, коробка списывается. Терпения у возвращающих клиентов нет.
- В итогах: «Принято возвратов: N».

## Модель
- Core: `Visit` (заказ или `ReturnRequest`) — очередь `Shift` теперь из визитов; `PickupDesk.OpenReturn`,
  `ActiveReturn`, `HasCustomer`, `ScanStatus.ReturnAccepted`, события `ReturnOpened`/`ReturnAccepted`;
  `ShiftStats.ReturnsAccepted`, `ScoringRules.ReturnService`.
- Runtime: коробка возврата (универсальный префаб + рантайм-QR) у клиента, `QrBox.PresentForScan`, тексты в презентере.

## Критерии приёмки
- EditMode: появление возврата, приём сканом, очки, нельзя открыть заказ во время возврата, коробка возвращается
  один раз, смена не заканчивается при ожидающем возврате.
- PlayMode: клиент ставит коробку в зону, скан принимает возврат, коробка исчезает.
