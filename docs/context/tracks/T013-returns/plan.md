- `Visit` получил явный `VisitKind` и `ReservedOrderNumber`; `Shift` больше не проверяет `!IsReturn` в правилах очереди.
- Проданные id запоминаются: поставка не может привезти их повторно; скан коробки возврата проверяется раньше приёмки.
- Коробка возврата кладётся на `HandoverZone.ReturnSpot` — рядом с зоной, а не в неё (не толкает подготовленные коробки).
- Директор не ветвится по виду визита: коробку кладёт обработчик `Desk.ReturnOpened`; передача заранее
  подготовленных коробок — только если открыт заказ, вне события (Core не входит сам в себя).
- Убран «бесплатный» приём возврата без коробки: без префаба возвраты выключаются с ошибкой.
- Табло: при возврате выдача в зону подсказывает «Сейчас идёт возврат», приёмка поставки — по `HasCustomer`.
- `ShiftStats.LastReturnPoints` → `PointsPerReturn`; PlayMode-тест берёт коробку из `ShiftDirector.CurrentReturnBox`.
