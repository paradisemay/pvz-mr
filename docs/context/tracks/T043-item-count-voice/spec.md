# T043 — Счёт товаров и русская озвучка сканера (#83)

Из #73: «на сканере пишется тот/не тот заказ; ещё желательно озвучка типа „товаров 8, отсканировано 7“… хотя бы
надпись, по возможности озвучку голосом на русском».

## Решение
- **Счёт** (ядро): `ServiceSession.ScannedCount` — товары заказа, найденные сканером, плюс выданные без скана (счёт
  не отстаёт от выданного); повторный скан той же коробки не считается дважды. `ScanOutcome` несёт
  `ItemsInOrder`/`ItemsScanned` для «Тот»/«Не тот заказ».
- **Сканер**: под вердиктом — «Товаров: 3 / Отсканировано: 2» (меньшим шрифтом). Без клиента у стойки — без счёта.
- **Компьютер**: «Товаров: 2 · выдано: 1» и «Отсканировано: 2».
- **Голос**: клипы заранее записаны голосом Windows **Microsoft Irina (ru-RU)** — `tools/make-voice.ps1`
  (System.Speech, 22 кГц моно, тишина по краям обрезана ffmpeg): «Тот заказ», «Не тот заказ», «Заказ выдан»,
  «Товаров», «отсканировано», числа «ноль»…«двадцать» (26 клипов, ~0,8 МБ). `ScannerVoice` на сканере (3D-звук из
  руки) проигрывает фразу по порядку после короткой паузы (сначала слышен сигнал скана); новая фраза обрывает
  старую. Тот заказ — «Тот заказ. Товаров восемь, отсканировано семь»; не тот — «Не тот заказ»; заказ закрыт —
  «Заказ выдан». Больше 20 товаров — вердикт без чисел.
- Пульт: `state` → `voice` (последние сыгранные клипы).

## Проверка
- EditMode: счёт в ядре (`ItemCountTests`), фразы и текст сканера, все клипы в префабе (`ScannerVoiceTests`),
  текст компьютера.
- Скриншоты: `27_scanner_count` (экран сканера), `19_computer_shift` (компьютер).
