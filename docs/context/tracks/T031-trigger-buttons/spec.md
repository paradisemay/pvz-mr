# T031 — Кнопки нажимаются курком (#74)

Из #73, п. 1: «Управление иногда на граб вместо клика».

## Было
Все кнопки стойки — `XRSimpleInteractable`, срабатывали на `selectExited`, то есть на отпускание **хвата (grip)**. Курок по
кнопкам ничего не делал. Логика нажатия была скопирована в пяти классах.

## Решение
- Общая компонента `PressableButton`: нажатие **курком**, пока луч наведён на кнопку, или **касанием** (poke) вблизи.
  Хват кнопку не нажимает.
- Курок не нажимает кнопку, если рука уже что-то держит (сканер): прицеливание сканером не жмёт кнопку за коробкой.
- XRI отдаёт activate только выбранному объекту, поэтому курок читается у наводящего интерактора
  (`XRBaseInputInteractor.activateInput.ReadWasPerformedThisFrame`).
- Одно нажатие курка/касания — одно срабатывание (защита от повторов 0,35 с); видимый отклик — подсветка при наведении
  и «вдавливание» колпачка.
- Пять кнопок (`DifficultyButton`, `RecenterButton`, `ResetWarehouseButton`, `ThemeButton`, `RestartButton`) подписаны на
  `PressableButton.Pressed`.
- Пульт: `hand aim <часть имени кнопки>` — навести виртуальную руку на кнопку (проверка на шлеме).

## Проверка
- EditMode: кто может нажать (курок с пустой рукой — да, со сканером — нет, хват — нет, касание — да).
- PlayMode: у всех кнопок сцены есть `PressableButton`; нажатие запускает смену.
- Quest 3, виртуальный контроллер пульта: хват по «Обычная» — смена не началась; курок — началась; подсветка при наведении.
