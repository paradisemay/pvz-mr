# T048 — Три темы ПВЗ: «Азот», «Разборы», «Рынок» (#87)

Из #73: «тем основных три: синяя, фиолетовая и оранжево-красная… для синей темы название „Азот“, для фиолетовой —
„Разборы“, для оранжево-жёлтой — „Рынок“… чтобы название заменялось».

## Решение
- Каталог тем (T022) заменён тремя темами, открытыми сразу (без очков карьеры):
  - **«Азот»** — тёмно-синий корпус, голубая столешница, розовый акцент;
  - **«Разборы»** — пурпурный корпус, белая столешница и акцент;
  - **«Рынок»** — оранжевый корпус, жёлтая столешница, красная окантовка.
- Тема красит стойку, рамки табло и списка заказов, корпус компьютера и стойки стеллажа (`CounterSkin`), и меняет
  **название ПВЗ**: вывеска стойки «АЗОТ / пункт выдачи», заголовок компьютера «АЗОТ · СМЕНА».
- Выбор — клавиша «ТЕМА» в настройках компьютера (по кругу), сохраняется (`Career.ThemeKey`); сохранённая старая
  тема карьеры откатывается на первую. Карьера остаётся очками и рекордами.
- Совмещено с оформлением ITMO (PR #111): сцена пересобрана сборщиком, коробки и посетители ITMO на месте.

## Проверка
- EditMode: каталог — три открытые темы с названиями; PlayMode: клавиша переключает «Азот» → «Разборы» → «Рынок» →
  «Азот», вывеска и заголовок компьютера меняются, выбор сохраняется.
- Скриншоты: `15_theme_azot`, `32_theme_razbory`, `33_theme_rynok`.
