## По итогам ревью
- Часы вынесены в отдельный тип Core `ShiftClock`; `Shift` решает только последствия.
- Смена, закончившаяся раньше лимита, останавливает часы: «Время вышло» больше не затирает итоги (тест).
- После итогов ввод (сканер, зона выдачи) игнорируется — очки не меняются после отправки рекорда.
- Нет мигания подсказки поставки, когда очередь ушла во время заполнения.
- Параметры пресетов передаются явно (без значений по умолчанию); `architecture.md` — «Решения T015».
- Отложено: «итоги в презентере» (`Show(..., endedByTime)`) — вынести формирование текста итогов при следующем изменении панели.
