# T024 — Памятка «Как играть»

## Зачем
Шлема у разработчика не было: первый прогон APK на Quest проведёт кто-то другой, без объяснений. Короткая памятка на стойке
— самый дешёвый способ сделать первую сессию возможной без автора.

## Что делаем
- В стартовом меню, слева от табло (зеркально списку заказов), — карточка «КАК ИГРАТЬ»: сканер → номер заказа → найти
  коробку сканером → в зелёную зону → пакет → возврат → поставка; внизу — управление (захват — кнопка захвата, скан — курок).
- Карточка — часть стартового меню: скрывается вместе с ним при выборе сложности, возвращается после «Новой смены».

## Архитектура
- Текст — `ShiftPresenter.HowToPlayText`; пишет его презентер в `ShowDifficultyMenu` (не вшит в сцену при сборке),
  карточка — ссылка `CounterBoard` (`ShowHowToPlay`). Коллайдеров у карточки нет — не мешает сканеру и поставке.

## Критерии готовности
- Editor: в тексте есть все шаги (включая пакет и возврат) и управление. PlayMode: карточка видна в меню с текстом
  презентера и пропадает при старте смены. Скриншот `16_how_to_play.png`; ревью; PR в `dev`; релиз v1.16.0.
