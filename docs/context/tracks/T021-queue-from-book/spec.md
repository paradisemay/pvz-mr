# T021 — Очередь как вид книги заказов

## Зачем
После T019 «кто ждёт» хранилось дважды: в очереди `Shift._line` и в `OrderBook`. Ревью архитектуры T019 назвало это
двумя источниками правды; согласованность держал только тест. Технический долг — без изменения поведения.

## Что делаем
- `OrderBook.Line` — открытые визиты (ждут или у стойки) в порядке прихода; список поддерживается книгой при переходах,
  не пересчитывается (директор опрашивает очередь каждый кадр).
- `Shift` больше не хранит очередь: `QueuedVisits`, `QueuedOrders`, `CanEnqueue`, `OpenNext`, резервы, `LeaveQueue`,
  конец времени и `IsOver` читают `Book.Line`; выдача, уход без заказа и возврат убирают клиента из очереди переходом
  книги (раньше — отдельным удалением из `_line`).

## Критерии готовности
- Поведение не меняется: все EditMode- и PlayMode-тесты проходят без правок, тест «открытые записи = очередь» остаётся.
- Ревью; PR в `dev`; релиз v1.13.0.
