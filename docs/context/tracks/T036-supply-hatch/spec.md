# T036 — Люк поставки: куча коробок в начале смены (#80)

Из #73: «коробки появляются просто рандомно; пусть пользователь сам выберет на потолке дырку-дроп, откуда коробки будут
выпадать кучей; коробок немного больше, чем заказов… в начале каждой смены прилетает эта куча и падает в одно место».

## Было
- Коробки склада стояли заранее по комнате (T017 — раскладка запоминалась; T020 — «Сбросить склад»).
- Поставка падала с потолка в случайные свободные точки вокруг игрока.

## Решение
- **Люк поставки** (`SupplyHatch`) под потолком: рамка, створки, шнур с ручкой. Высота — по плоскости потолка AR, иначе по
  настройкам. Место люка — в настройках компьютера («Место люка»), переносится ручкой как стойка (тот же механизм, теперь
  общий: `PlacementKeeper` / `PlacementMover`, у каждого объекта свой ключ сохранения), сохраняется между запусками.
- **В начале каждой смены** из люка струёй выпадают все коробки заказов смены и **запасные** (`ShiftSettings.SpareBoxes`,
  по умолчанию 2: чужие заказы — «на другой день»); порядок перемешан. Коробки падают физикой и ложатся кучей. Клиенты
  приходят, когда куча упала.
- **Запасные коробки** (Core `Shift.MarkNotForSale`): за ними никто не приходит, в итог смены не идут, скан — «не тот заказ»,
  после смены остаются на складе.
- **Поставка** по ходу смены (T004) — тоже из люка.
- Потерянная коробка (упала сквозь пол, улетела) снова выпадает из люка.
- **Убрано:** заранее разложенный склад, запоминание раскладки (T017), «Сбросить склад» (T020), префабы коробок по номерам.

## Проверка
- EditMode: запасные заказы — никто не приходит, не в счёт, смена кончается с ними на складе, скан — другой заказ.
- PlayMode: куча — ровно коробки смены и запасные, все лежат под люком на полу; перенос люка ручкой сохраняет место
  (свой ключ), куча следующей смены падает под новое место; потерянная коробка — снова из люка; полная смена (поставка из
  люка, запасные остаются).
- Quest 3: начало смены — коробки выпали из люка и легли на реальный стол по плоскостям комнаты (`pile-device-overview.png`).
