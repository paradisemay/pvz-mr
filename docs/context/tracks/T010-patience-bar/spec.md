# T010 — Индикатор терпения

## Зачем
С T006 клиенты уходят, если их долго не обслуживать, но игрок не видит, сколько осталось. Полоска над головой
клиента делает правило видимым («клиенты начинают торопить игрока» из концепции).

## Правила
- Над головой клиента у стойки — полоска: полная зелёная → жёлтая → красная к концу терпения.
- Нет полоски, если терпение бесконечно (Лёгкая) или клиенту уже начали выдавать заказ (он больше не уходит).

## Модель
- Core: `Shift.PatienceRemaining(now)` → доля 0..1 или `null`, когда терпение не тикает.
- Runtime: `PatienceBar` (billboard, цвет по доле) на префабе клиента; `ShiftDirector.Update` передаёт долю клиенту у стойки.

## Критерии приёмки
- EditMode: доля убывает со временем, `null` при бесконечном терпении/без клиента/после частичной выдачи.
- PlayMode: полоска видна и убывает на «Обычной», скрыта при бесконечном терпении.
