# T007 — Очередь клиентов

## Зачем
Из концепции: «большая очередь клиентов», «одновременно появляется несколько клиентов». Игрок видит, что его ждут,
и это создаёт давление темпа без новых правил выдачи.

## Правила
- Перед стойкой — очередь до `queueLength` клиентов (Лёгкая 1, Обычная 2, Сложная 3). Обслуживается первый,
  остальные стоят в линию за ним и подходят ближе, когда первый уходит.
- У каждого клиента в очереди свой заказ; **два клиента никогда не приходят за одним заказом** (заказ резервируется
  за клиентом при появлении). Заказ ушедшего без покупки клиента снова доступен.
- Терпение по-прежнему считается только у стойки.

## Модель
- Core: резервирование заказов в `Shift` (`NextOrder` резервирует, `HasUnreservedOrders`, освобождение при
  выдаче/уходе), `OrderGenerator` с исключениями.
- Runtime: `Customer.GoTo` (одна активная прогулка), `Customer.LeaveAndVanish`, очередь в `ShiftDirector`
  (места в линию от стойки к точке появления), `ShiftSettings.queueLength`.

## Критерии приёмки
- EditMode: резерв, отсутствие повторов, освобождение при уходе, конец смены.
- PlayMode: при очереди 2 у стойки стоят два клиента с разными заказами; полная смена проходится.
