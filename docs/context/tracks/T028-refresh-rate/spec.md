# T028 — 90 Гц на Quest 3

На шлеме (T026) игра шла 72/72 FPS при GPU 23 % и CPU 14 % — запас большой, а 90 Гц заметно плавнее для рук и коробок.

## Решение
- `DisplayRate`: при старте на Android спрашивает у шлема поддерживаемые частоты (Meta Display Utilities, `XR_FB_display_refresh_rate`) и просит 90 Гц; если 90 нет — наибольшую ниже. 120 Гц не берётся: батарея и нагрев ради малой пользы в игре стоя.
- Выбор частоты — чистая функция `DisplayRate.Pick` с тестами.
- Пульт: в `state` есть `hz` — текущая частота.

## Проверка на Quest 3
- Поддерживаются 72, 80, 90, 120; запрошено 90 — `72 -> 90 Hz`.
- Сложная смена на автопилоте: 90/90 FPS, 1 пропущенный кадр за смену, GPU ≈ 29 %, CPU ≈ 20 %, 36 °C.
