# T025 — Общие границы склада

## Зачем
Отложенный пункт из T017: «где может быть коробка» было записано дважды — в `BoxPlacement` (6 м, пол, потолок) и
в `QrBox` (сериализованное поле «потеряна дальше 6 м»). Настроив одно, можно было разойтись с другим: игра восстановила бы
коробку туда, где сама же считает её потерянной.

## Что делаем
- Core `WarehouseBounds`: досягаемость (6 м по горизонтали от центра игровой зоны), высота центра коробки (0.05–3 м).
- `BoxPlacement.IsPlausible` и проверка «потерянной коробки» в `QrBox` используют это правило; поле `lostBeyondMeters` убрано.
  Проверка падения сквозь пол (`lostBelowY`, мировая высота) осталась отдельной: это другое событие.
- Поведение не меняется.

## Критерии готовности
- EditMode: граница досягаемости, NaN, совпадение `BoxPlacement.IsPlausible` с правилом. Все прежние тесты проходят.
- Ревью; PR в `dev`; релиз v1.17.0.
