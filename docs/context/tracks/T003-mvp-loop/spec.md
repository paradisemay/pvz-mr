# T003 — MVP-цикл в сцене

## Зачем
Собрать «Минимальный прототип» из концепции в одну играбельную сцену.

## Сцена `Assets/_Project/Scenes/Game.unity`
- **XR Origin (XR Rig)** из XRI Starter Assets + `ARSession`, `ARCameraManager` на камере (passthrough), `ARPlaneManager`.
- **Камера**: фон — прозрачный чёрный (passthrough на устройстве).
- **Мок-комната** (только в редакторе): пол, стены, стол — чтобы играть в XR Interaction Simulator.
- **Стойка ПВЗ** в 1,2 м перед игроком: столешница, табло, зона выдачи.
- **Ручной сканер** на стойке: берётся рукой, курок → луч → экран сканера показывает номер заказа коробки.
- **3 коробки** `BOX-001..003` (заказы 1435, 2781, 5812) в разных местах комнаты, QR — текстура на гранях.
- **Клиент**: выходит из-за стойки, говорит номер заказа, ждёт; на неправильную коробку — «Это не мой заказ»,
  на правильную — «Спасибо!», забирает коробку и уходит. Следующий клиент — через паузу.
- **Табло**: текущий заказ, очки, выдано X/3. После последней коробки — «Смена завершена» + статистика.

## Критерии приёмки
- Сцена генерируется `PvzSceneBuilder.BuildAll` в batchmode.
- PlayMode-тест: клиент приходит → скан правильной коробки даёт `Matches` → коробка в зоне выдачи → заказ закрыт, очки начислены.
- Скриншот сцены приложен к PR.
