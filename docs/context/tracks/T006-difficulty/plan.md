## По итогам ревью
- **High (оба ревью):** клиент, ушедший после частичной выдачи, уносил коробки → заказ терялся или выдавался неполным.
  Правило: клиент, которому начали выдавать заказ, больше не теряет терпение (Core + тест).
- `Start` не показывает меню, если смена уже запущена; `Begin` проверяет `isActiveAndEnabled`.
- Штраф за ушедшего клиента — в `ShiftSettings`; пресеты при создании копируют раскладку коробок из «Обычной».
- Попутно: сборка APK падала на валидации OpenXR — `PvzProjectSetup` теперь применяет автоматические исправления
  (Composition Layers Support) и выключает SSAO в мобильном рендерере.
