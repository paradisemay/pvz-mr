# T006 — Сложность и терпение клиентов

## Зачем
Из концепции: «Система сложности» (на старте — мало коробок и без требований; дальше — клиенты торопят,
ограничение времени, пакеты, поставки). Даёт реиграбельность и делает смену напряжённее.

## Правила
- **Выбор сложности.** Перед сменой на стойке три кнопки: «Лёгкая», «Обычная», «Сложная»; табло просит выбрать.
  Нажатие запускает смену с соответствующим `ShiftSettings`.
  - Лёгкая: без поставки, без пакетов, терпение без ограничения.
  - Обычная: поставка после 1-го клиента, пакет 50 %, терпение 90 с.
  - Сложная: поставка после 1-го клиента, пакет 80 %, терпение 45 с, клиенты подходят быстрее.
- **Терпение.** У клиента есть `patienceSeconds` (0 = бесконечно). На 60 % клиент торопит: «Побыстрее, пожалуйста!».
  Когда терпение кончилось — клиент уходит ни с чем: заказ **не выдан**, −50 очков, «Ушёл без заказа: N» в итогах.
  Коробки заказа остаются на складе — за ними придёт следующий клиент.
- Рейтинг смены учитывает ушедших клиентов (как ошибочные выдачи).

## Модель
- Core: `ServiceSession` знает своё терпение; `Shift.Tick(now)` → события `CustomerHurried` (один раз), `OrderAbandoned`;
  `PickupDesk.Abandon(now)`; `ShiftStats.OrdersAbandoned`, штраф `ScoringRules.AbandonPenalty`.
- Runtime: `DifficultyButton` (XRSimpleInteractable) → `ShiftDirector.Begin(settings)`; презентер: реплики и табло;
  `ShiftDirector.Update` вызывает `Shift.Tick`.
- Editor: три ассета `ShiftSettings_Easy/Normal/Hard`, кнопки на стойке.

## Критерии приёмки
- EditMode: торопит один раз, уход по таймеру, заказ остаётся на складе, штраф, бесконечное терпение.
- PlayMode: выбор сложности запускает смену; клиент на «Сложной» уходит, если ничего не делать.
