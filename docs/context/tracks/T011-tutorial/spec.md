# T011 — Подсказки на первом заказе

## Зачем
Новичок в VR не знает, что сканер берут со стойки, сканируют курком, а коробку кладут в зону выдачи.
На «Лёгкой» первый заказ сопровождается пошаговыми подсказками на табло.

## Правила (только при `showTutorial`, по умолчанию — Лёгкая, только до первой выдачи)
1. Клиент подошёл, сканер не в руке → «Возьмите сканер со стойки».
2. Сканер в руке → «Наведите сканер на коробку и нажмите курок».
3. Отсканирована нужная коробка → «Отнесите коробку в зелёную зону на стойке»; не та → «Это не та коробка — ищите № заказа клиента».
4. Заказ выдан → подсказки выключаются.

## Модель
- Runtime: `HandScanner.Grabbed`; шаги и тексты — в `ShiftPresenter`; `ShiftSettings.showTutorial`.

## Критерии приёмки
- PlayMode: на «Лёгкой» подсказки идут по шагам; на «Обычной» их нет.
