# T041 — Меш комнаты Meta как физика (#82)

Из #73: «коробки отскакивают словно от кровати, которая стоит в комнате, — считается физикой по сетке Meta».

## Было
Только плоскости AR (пол, стены, стол, потолок). Меш комнаты не использовался (функция «Meta Quest: Meshing» выключена).

## Решение
- Включена функция OpenXR **«Meta Quest: Meshing»** (`PvzProjectSetup`, Android).
- `Room Mesh` — дочерний объект XR Origin: `ARMeshManager` с префабом `RoomMeshChunk` (только `MeshFilter` +
  `MeshCollider`, без рендерера — поверх passthrough ничего не рисуется). Сохранён выключенным; включается
  `ScenePermissionGate` вместе с плоскостями (то же разрешение `USE_SCENE`).
- `RoomMesh` — состояние меша: `Off` (нет подсистемы: редактор, Link, нет разрешения), `Waiting`, `Ready`,
  `Missing` (подсистема работает 8 с, а меша нет). При `Missing` меню компьютера пишет
  «Мебель не найдена: отсканируйте комнату в настройках шлема», игра идёт на плоскостях и невидимом полу.
- Пульт: `state` → `roomMesh`, `roomMeshes`.

## Проверка
- EditMode: состояние по данным шлема (`RoomMeshStateTests`); целостность сцены: менеджер под XR Origin, выключен,
  префаб — невидимый коллайдер, гейт ссылается на него.
- PlayMode: меню показывает сообщение при `Missing` и убирает его при `Ready`; в редакторе (без подсистемы) — молчит.
- Скриншот `26_room_not_scanned`.
- **Quest 3: меш не пришёл.** Подсистема запускается (`roomMesh: Waiting` → `Missing`), сообщение на компьютере
  показывается. Причина в logcat: все запросы среды Meta к пространствам (`xrDiscoverSpacesMETA`) — и для меша
  (компонент `TRIANGLE_MESH`), и для плоскостей (`BOUNDED_2D`) — отклоняются: `ERROR_PACKAGE_UNTRUSTED`,
  `rpcAllowed: false`. Разрешения `USE_SCENE` и `USE_ANCHOR_API` выданы. По отчётам Meta это доверие к пакету на
  уровне устройства (например, шлем зарегистрирован в Meta Quest for Business) — кодом приложения не исправляется.
  Поэтому «коробки лежат на реальной мебели» на этом шлеме **не проверено**; #82 закрыта как «не планируется» с этим
  комментарием, код (меш + запасной путь) слит.
