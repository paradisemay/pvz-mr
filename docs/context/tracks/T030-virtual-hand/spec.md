# T030 — Виртуальный контроллер для пульта

До сих пор пульт играл смену на уровне игры (`scan`, `give`, автопилот) — путь ввода XRI на шлеме не проверялся.
T030 добавляет правый контроллер, которым управляет пульт: устройство `XRSimulatedController` в Input System, так что работают
настоящие действия XRI (`XRI Right Interaction/Select`, `Activate`), Near-Far Interactor и захват сканера.

## Команды (только отладочная сборка)
- `hand on|off` — подключить/убрать контроллер (XRI переключается в режим контроллеров);
- `hand aim scanner|BOX-ID|x y z` — рука тянется к цели и наводит луч; если в руке сканер — наводится луч сканера;
- `hand grip on|off`, `hand trigger on|off`;
- `hand` — состояние: режим ввода, интеракторы, что подсвечено и выбрано, действия Select/Activate, дуло сканера, экран сканера.

## Найдено при отладке на Quest 3
- Состояние нужно писать через `InputState.Change` рано в Update (как симулятор XRI): событие из очереди съедал проход ввода
  перед рендером, и интерактор не видел «нажато в этом кадре» — Select был `Performed`, а выбора не было.
- Шлем лежит на столе ниже стойки: луч из-под стойки упирался в её корпус — рука ставится рядом с целью и выше неё.

## Проверено на Quest 3
- `mode: MotionController`, луч Near-Far подсвечивает сканер, `grip` — сканер выбран (`selected: Near-Far Interactor:HandScanner`).
- `trigger` — сканер срабатывает (экран: «Нет кода в прицеле»).

## Не сделано
- Скан коробки виртуальной рукой: луч сканера пока не попадает в коробку (вероятно, дальность или геометрия — не разобрано).
  Следующий шаг: `hand` показывает дуло сканера; сравнить с позицией коробки и дальностью луча.

## По итогам ревью
- С подключённым настоящим правым контроллером XRI увидит две правые руки — `hand on` только для отладки без контроллеров.
- `hand off` останавливает и наведение.
